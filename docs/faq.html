IDM Navigator Heat Pump FAQ

Answers for developers and Home Assistant users who want to monitor or control an IDM Navigator heat pump locally with Python and Modbus TCP.

Can I connect an IDM heat pump to Python?

Yes. Install idm-heatpump-api[pymodbus] and use IdmModbusClient to communicate with the local IDM Navigator controller over Modbus TCP.

Does the IDM Heatpump API work with Home Assistant?

Yes. The library powers the unofficial IDM Heatpump Home Assistant integration.

Which IDM Navigator models are supported?

The project targets IDM Navigator 2.0, Navigator 10 and Navigator Pro. Navigator 1.0 and 1.7 are separate protocol families.

Is an IDM cloud account required?

No. Communication takes place locally through the IDM controller's Modbus TCP interface, normally on port 502.
